# Tarrant Appraisal District citizen engagement (prototype)

Scripted sample by [92 Logics](https://www.92logics.com). It is not an official Tarrant Appraisal District system and it is not a bid.

Buyer: Tarrant Appraisal District.

Notice: https://www.tad.org/content/rfp/TAD_AI_Citizen_Engagement.pdf

The assistant is scripted from that public RFP only. It refuses questions the RFP does not cover, including a person’s property value, account, tax bill, exemption eligibility, or protest outcome. Figures it quotes, including the 2024 call and counter counts, are the counts printed in RFP section 3.1, not a live district report and not numbers added for this demo.

Solicitation contact printed in the RFP: Greg Garza, ggarza@tad.org. Written questions are due Monday, October 5, 2026 at 5:00 p.m. Central Time. Proposals are due Wednesday, October 21, 2026 before 10:00 a.m. Central Time, delivered to 2500 Handley-Ederville Road, Fort Worth, Texas 76118. This folder does not include addenda.

## Run it

Open `index.html` in a browser. No install and no build step. No network connection and no API key are required.
